# Security

This project installs shell shortcuts and can run the upstream `actuallymentor/battery` installer.

## Recommended install practice

Prefer inspecting the installer before running it:

```bash
curl -fsSLO https://raw.githubusercontent.com/helbertm/macbook-battery-shortcuts/main/scripts/install.sh
less install.sh
bash install.sh
```

## Reporting issues

For security-sensitive concerns, avoid posting secrets or private machine details in public issues. Open a minimal public issue describing the category of problem, or contact the maintainer through GitHub.
